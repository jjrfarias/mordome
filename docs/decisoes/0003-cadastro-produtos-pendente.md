# ADR 0003: Adiar cadastro de produtos

- Estado: proposta bloqueada por decisão de produto
- Data: 2026-09-11

## Contexto

O cadastro depende de decisões sobre catálogo compartilhado, preços por unidade, variações, complementos e estoque.

## Decisão temporária

Não criar interface, API ou regras de cadastro de produtos antes de conversar com o responsável pelo produto. O esquema contém apenas uma referência mínima para preservar a integridade dos itens de venda.

## Consequências

Produtos demonstrativos permanecem locais. A fundação de organização, autorização, caixa, venda e auditoria pode avançar sem fechar prematuramente o modelo de catálogo.
